로또 6/45 번호 추첨기

버튼을 누르면 1부터 45까지의 숫자에서 본번호 6개와 보너스 번호 1개를 뽑아 5게임으로 보여 줍니다. 결과는 컴퓨터의 난수이며, 실제 추첨 결과나 당첨을 예측하지 않습니다.

각 게임 아래에는 번호를 만든 시각이 yyyy.mm.dd 시:분:초 형식으로 표시됩니다.

이 사이트가 하는 일

이 사이트는 한국에서 흔히 말하는 로또 6/45 형식, 즉 1~45 가운데 서로 다른 6개 번호와 보너스 1개를 화면에 보여 주는 도구입니다. 방문자가 번호를 고를 때 참고할 수 있도록 만들었으며, 동행복권이나 복권위원회와는 관련이 없습니다.

번호는 사람이 손으로 고른 것처럼 보이게 정렬만 하고, 선택 자체는 매번 새로 무작위로 이뤄집니다. 같은 버튼을 여러 번 눌러도 이전 결과가 다음 결과에 영향을 주지 않습니다.

사용 전에 알아 두면 좋은 점

  • 이 도구는 재미와 번호 고르기 보조 용도입니다. 당첨을 약속하지 않습니다.
  • 복권을 사려면 공식 판매점이나 공식 온라인 채널을 이용해야 합니다.
  • 청소년은 복권을 구매할 수 없습니다. 이 사이트도 구매를 대행하지 않습니다.
  • 광고가 표시될 수 있으며, 광고와 번호 결과는 서로 무관합니다.

규칙과 화면 보는 법은 이용 안내에, 조합이 얼마나 많은지는 확률 설명에 따로 정리했습니다. 사이트 운영 목적은 소개에서 확인할 수 있습니다.

번호 색이 의미하는 것

화면에 나오는 공 색깔은 당첨 여부를 나타내지 않습니다. 1~10, 11~20, 21~30, 31~40, 41~45처럼 구간을 나누어 한눈에 구분하기 쉽게 칠한 것입니다. 보너스 번호만 점선 테두리로 구분합니다.

개인정보처리방침 소개 문의 이용 안내

이 사이트는 동행복권 공식 서비스가 아닙니다. 제공 번호는 무작위 예시이며 당첨을 보장하지 않습니다.
